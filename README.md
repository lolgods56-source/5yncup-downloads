# 5yncUp

Установочные файлы 5yncUp доступны в [Releases](https://github.com/lolgods56-source/5yncup-downloads/releases). Библиотека при первом запуске пустая. Данные слушателя хранятся на его устройстве.

- **Mac с Apple Silicon.** Распакуйте ZIP и откройте 5yncUp.app. С версии 0.2.10 новые сборки можно устанавливать из самого 5yncUp.
- **Windows x64.** Распакуйте ZIP целиком и запустите 5yncUp.exe из распакованной папки. С версии 0.1.2 новые сборки можно устанавливать из самого 5yncUp.
- **Android.** Откройте APK на телефоне и подтвердите установку. 5yncUp сообщит о новой версии и откроет загрузку APK. Android предложит подтвердить обновление.

Приложения проверяют [список обновлений](desktop-updates.json) при запуске. GitHub обновляет список при публикации релиза.
