# 5yncUp

Установочные сборки и обновления 5yncUp. Исходники и данные слушателей хранятся отдельно.

Откройте [Releases](https://github.com/lolgods56-source/5yncup-downloads/releases)
и выберите архив для своей платформы.

Версии для Mac и Windows проверяются по [списку обновлений](desktop-updates.json).
При публикации нового релиза GitHub обновляет список автоматически.
